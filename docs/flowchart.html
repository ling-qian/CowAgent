5. 多租户数据隔离 安全模型

🔐 认证隔离
每个请求通过 API Key 识别租户
g.tenant_id 贯穿请求生命周期
无 Key → 401 Missing tenant auth
📊 数据隔离
所有查询自动添加 tenant_id 过滤
API Key 绑定租户
无法跨租户访问数据
⏱️ 限流隔离
每租户独立限流计数
Free/Pro/Enterprise 不同配额
超限返回 429 Too Many Requests
📝 审计隔离
每租户独立审计日志
记录所有敏感操作
支持 GDPR 数据导出/删除
